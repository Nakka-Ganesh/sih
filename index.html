DPDP ACT 2023 Security & Privacy Architecture

Citizen data comes with responsibility.

DialIQ incorporates defense-in-depth privacy principles. The AI is completely separated from direct database execution.

🔒

1. Explicit Consent

Citizen is prompted for plain-language consent before any departmental record is fetched.

👤

2. Phone Auth & JWT

Verified mobile number & simulated OTP session tokens (HS256) with short expiration times.

🛡️

3. Minimal Data Scope

Fetches only the specific application status or benefit field needed for the conversational answer.

📜

4. Cryptographic Audit

Immutable transaction logs with unique Request IDs (DQ-2026-XXXX) and latency metrics.
